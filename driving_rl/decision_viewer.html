How to read the curves

QR-DQN predicts 32 return quantiles for each action. The mean selector averages them all. The cautious selector sorts the predictions and averages the lowest quarter. The graph shows raw output-head order so prediction crossings remain visible. Training uses mean-based next-action selection; deploying a different selector changes the continuation policy.

DQN predicts one expected-return estimate per action. A scalar mean is not a return distribution, so the viewer does not draw it as a quantile curve. A low predicted return can describe several bad outcomes; it is not a calibrated probability of a crash.

Gap and speed readouts come from simulator measurements for explanation. Those extra measurements are not passed to the learned network. A nearby vehicle or recent lane change does not by itself establish the cause of a collision.
